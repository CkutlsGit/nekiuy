# Nekiuy

Spring Java Core - Учебное приложение

## 📋 Обзор

Учебное приложение на **Spring Java Core** с базой данных **H2**, созданное для изучения. Использует **логические представления** - то есть возвращает шаблон (view), а не тело ответа (JSON).

Суть проекта заключается в создании полка и добавлении в него людей с последующим отображением этих данных.

## 🚀 Стек

### Backend
- **Java 17+** - основной язык
- **Spring Boot** - фреймворк приложения
- **Spring MVC** - веб-слой с логическими представлениями
- **Spring Data JPA** - доступ к базе данных и ORM

### База данных
- **H2** - встроенная база данных для обучения

## ✨ Возможности

- 🔐 **Управление полками**
  - Создание полка
  - Отображение списка полков

- 👤 **Управление людьми**
  - Добавление человека в полк
  - Отображение людей, закреплённых за полками

- ✅ **Логические представления**
  - Возвращает шаблоны (views) вместо JSON-ответов
  - Редирект на главную страницу после отправки формы

## 🛠️ Быстрый старт

### Требования
- JDK 17+
- Maven 3.6+ (или Gradle)
- Git

### Установка и запуск

1. **Клонирование репозитория**
```bash
git clone https://github.com/CkutlsGit/nekiuy
cd nekiuy
```

2. **Сборка и запуск через Maven**
```bash
./mvnw spring-boot:run
```

На Windows:
```bash
mvnw.cmd spring-boot:run
```

Или, если `mvnw` отсутствует, используйте системный Maven:
```bash
mvn spring-boot:run
```

3. **Доступ к приложению**
```
http://localhost:8080/
```

## 📚 API Endpoints

| Метод | Endpoint | Описание |
|--------|----------|-------------|
| GET | `/` | Главная страница |
| POST | `/add/rgt` | Добавление полка и редирект на главную страницу |
| POST | `/add/people` | Добавление человека в полк и редирект на главную страницу |

## 📦 Структура проекта

```
src/main/java/com/nekiuy/app/
├── controller/          # Spring MVC контроллеры
├── model/               # Модели и сущности JPA
├── repository/          # JPA репозитории
├── service/             # Бизнес-логики
└── AppApplication.java  # Точка входа приложения

src/main/resources/
├── templates/           # Шаблоны представлений (Thymeleaf / JSP)
└── application.properties
```
